# Approved standard package procedure — PROC-STD-01 version 1

Synthetic Stratos Silicon business procedure. Approved for Helios Atlas Inference,
PRG-A17, CFG-B-01 content version 1, ACCELERATOR-X REV-B, MODEL-LAB-07,
one device, FW-2.3, RT-4.1, QFMT-1 and MEM-1 only.

The existing WF-LC-V1 profile is approved: context bins 8192 and 32768,
concurrency 4, 1024 output tokens, a 120-minute suite with 60 minutes per bin.
CRIT-BASE-V1 content version 1 remains unchanged. This procedure does not approve
WF-LC-V2 or infer coverage from a larger context length.

Applicable completed historical evidence may be cited as profile evidence.
For a new acceptance package, Validation Operations must still verify the nominated
sample and input manifests, obtain separate lab authorization, and run the standard
120-minute confirmation suite on that sample. The previous pass does not complete
this package's work. Required inputs are the exact firmware/runtime manifests,
workload manifest, unchanged criteria and nominated sample identifier.

The completion criteria are a traceable intake, complete approved procedure/input
references and named remaining work. Intake receipt neither reserves a resource nor
authorizes a lab job. Numerical acceptance criteria remain outside this demo's
boolean-result convention. Engineering evidence review and customer acceptance are
separate downstream responsibilities.
